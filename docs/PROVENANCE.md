## 3. Compression & Optimization Pipeline

The raw GLTF/GLB models generated by Tripo (~44 MB each with uncompressed 4K textures) were optimized for 60 FPS mobile and desktop web rendering using `@gltf-transform/cli`:

```bash
gltf-transform optimize raw_input.glb output_optimized.glb \
  --texture-compress webp \
  --texture-size 1024 \
  --simplify-error 0.0008 \
  --meshopt
```

### Visual Verification Results
* Each compressed asset was rendered side-by-side against its raw original under identical three-point PMREM studio lighting.
* **Results**: Zero texture tearing, zero UV seam artifacts, and zero silhouette distortion. Fine details (button embossings, cord braiding, limestone pores) remain fully preserved.
* Comparison images are archived in `evidence/screenshots/*_comparison.png`.
